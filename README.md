*Fullstack-разработчик полного цикла*

* **Стек:** `C#`, `ASP.NET Core`, `PostgreSQL`, `Redis`, `Apache Kafka`, `Next.js`, `TypeScript`, `Docker`, `CI/CD`, `Ansible`, `Caddy`, `MinIO`, `Infisical`, `Ngrok`.
